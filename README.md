# Study Planner Dashboard

A simple student dashboard for managing daily study tasks, focus sessions, and revision goals in one place.

## Features

- Focus timer for study sessions
- Add and remove daily study tasks
- Goal tracking for study hours, revision topics, and practice questions
- Upcoming deadlines panel
- Quick access to useful learning resources
- Saves tasks in the browser using localStorage

## Project structure

```text
study-planner-dashboard/
├── index.html
├── styles.css
├── script.js
├── README.md
├── LICENSE
└── .gitignore
```

## Run locally

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## What this project demonstrates

This project is useful for students because it combines productivity and learning in a single interface:

- time management
- study tracking
- goal setting
- revision planning
- practical portfolio value
